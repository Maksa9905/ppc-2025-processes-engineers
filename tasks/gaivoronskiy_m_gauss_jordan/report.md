## 1. Введение

Метод Гаусса-Жордана — это численный метод решения систем линейных алгебраических уравнений (СЛАУ), который является модификацией метода Гаусса. Основное отличие заключается в том, что в методе Гаусса-Жордана матрица приводится не к ступенчатому виду, а к диагональному (единичному) виду, что позволяет сразу получить решение системы.

Цель работы — реализовать алгоритм решения СЛАУ методом Гаусса-Жордана, распараллелить его с помощью технологии MPI и провести сравнение производительности последовательной и параллельной версий.

## 2. Постановка задачи

**Входные данные:**
- Расширенная матрица системы уравнений размера N × (M+1), представленная в виде `std::vector<std::vector<double>>`
- N — количество уравнений
- M — количество переменных
- Последний столбец содержит свободные члены (правые части уравнений)

**Выходные данные:**
- Вектор решений размера M типа `std::vector<double>`
- В случае отсутствия решений или бесконечного множества решений возвращается пустой вектор

**Формат данных:**
```cpp
using InType = std::vector<std::vector<double>>;  // Расширенная матрица
using OutType = std::vector<double>;              // Вектор решений
```

**Ограничения:**
- Матрица должна быть прямоугольной (все строки имеют одинаковую длину)
- Количество столбцов должно быть на 1 больше количества переменных (включая столбец свободных членов)
- N > 0, M > 0

**Типы решений:**
1. Единственное решение — система имеет ровно одно решение
2. Нет решений — система противоречива (есть строка вида 0 0 ... 0 | b, где b ≠ 0)
3. Бесконечно много решений — ранг матрицы меньше количества переменных

## 3. Базовый алгоритм (последовательная версия)

Последовательный алгоритм метода Гаусса-Жордана состоит из следующих этапов:

### 3.1 Основной алгоритм

1. **Прямой ход — приведение к диагональному виду:**
   ```
   Для каждого столбца col от 0 до M-1:
     a. Найти опорный элемент (ненулевой элемент) в столбце col, начиная со строки row
     b. Если опорный элемент не найден, перейти к следующему столбцу
     c. Переставить строку с опорным элементом на позицию row
     d. Нормализовать строку row (разделить на опорный элемент, чтобы получить 1)
     e. Обнулить столбец col во всех остальных строках
     f. Увеличить row и col
   ```

2. **Извлечение решения:**
   ```
   a. Проверить на противоречивость (строка вида 0 0 ... 0 | b, где b ≠ 0)
   b. Вычислить ранг матрицы (количество ненулевых строк)
   c. Проверить на бесконечное множество решений (rank < M && rank < N)
   d. Извлечь решение из последнего столбца матрицы
   ```

### 3.2 Детали реализации

**Поиск опорного элемента:**
- Ищется первый ненулевой элемент в столбце, начиная с текущей строки
- Используется порог 1e-10 для проверки на ноль (из-за ошибок округления)

**Нормализация строки:**
- Вся строка делится на значение опорного элемента
- В результате опорный элемент становится равным 1

**Обнуление столбца:**
- Из каждой другой строки вычитается опорная строка, умноженная на коэффициент
- Коэффициент равен значению элемента в текущем столбце

**Сложность:**
- Временная: O(N²M) — для каждой переменной обрабатываются все строки и столбцы
- Пространственная: O(NM) — хранение расширенной матрицы

## 4. Схема параллелизации

### 4.1 Стратегия распределения данных

В параллельной версии используется стратегия **репликации данных**:
- Каждый процесс получает полную копию расширенной матрицы
- Все процессы выполняют одинаковые операции над матрицей
- После каждой итерации матрица синхронизируется между процессами через `MPI_Bcast`

**Обоснование выбора:**
- Метод Гаусса-Жордана требует доступа ко всей матрице на каждом шаге
- Распределение строк по процессам усложнило бы обмен данными при обнулении столбцов
- Репликация упрощает реализацию и обеспечивает согласованность данных

### 4.2 Коммуникационные операции

**PreProcessing:**
1. Процесс 0 получает матрицу из входных данных
2. Процесс 0 рассылает размеры матрицы (N, M) всем процессам через `MPI_Bcast`
3. Процесс 0 преобразует матрицу в одномерный массив и рассылает его через `MPI_Bcast`
4. Все процессы восстанавливают матрицу из одномерного массива

**Run (основной цикл):**
Для каждой итерации метода Гаусса-Жордана:
1. Все процессы ищут опорный элемент локально (результат одинаковый)
2. Процесс 0 выполняет перестановку строк, нормализацию и обнуление столбца
3. Процесс 0 синхронизирует опорную строку через `MPI_Bcast` перед обнулением
4. Все процессы выполняют обнуление столбца локально
5. Процесс 0 синхронизирует всю матрицу через `MPI_Bcast` после изменений
6. Все процессы синхронизируются через `MPI_Barrier`

**PostProcessing:**
1. Все процессы извлекают решение локально
2. Все процессы вычисляют локальные флаги (противоречивость, rank)
3. Процесс 0 собирает глобальные флаги через `MPI_Reduce`
4. Процесс 0 определяет тип решения и рассылает его всем процессам
5. Процесс 0 рассылает решение всем процессам через `MPI_Bcast`

### 4.3 Роли процессов

- **Процесс 0 (Master):**
  - PreProcessing: Получает матрицу, рассылает размеры и данные всем процессам
  - Run: Выполняет все операции над матрицей, синхронизирует результаты
  - PostProcessing: Определяет тип решения, рассылает результат

- **Процессы 1..P-1:**
  - PreProcessing: Получают размеры и данные матрицы
  - Run: Выполняют те же операции, что и процесс 0, синхронизируют данные
  - PostProcessing: Извлекают решение, участвуют в сборе флагов, получают результат

### 5.2 Ключевые особенности реализации

**Обработка нулевых элементов:**
- Используется функция `isZero()` с порогом 1e-10 для учета ошибок округления
- При поиске опорного элемента пропускаются столбцы, где все элементы нулевые

**Извлечение решения:**
- После приведения матрицы к диагональному виду решение находится в последнем столбце
- Каждая строка соответствует одной переменной (по первому ненулевому элементу)
- Если строка полностью нулевая, переменная считается свободной (значение 0)

**Проверка типа решения:**
- Противоречивость: строка с нулевыми коэффициентами и ненулевым свободным членом
- Бесконечное множество: rank < M && rank < N
- Единственное решение: иначе

### 5.3 Граничные случаи

- **N = M:** Квадратная система, обычно имеет единственное решение
- **N < M:** Недоопределенная система, обычно бесконечно много решений
- **N > M:** Переопределенная система, может быть противоречивой
- **Вырожденная матрица:** Все элементы столбца нулевые — пропускается

**Последовательная версия (SEQ) — основной алгоритм:**

```cpp
bool GaivoronskiyMGaussJordanSEQ::RunImpl() {
  if (GetInput().empty()) {
    return true;
  }

  std::vector<std::vector<double>> matrix = GetInput();
  int n = static_cast<int>(matrix.size());
  int m = (n > 0) ? static_cast<int>(matrix[0].size()) : 0;

  auto isZero = [](double value) { return std::fabs(value) < 1e-10; };

  // Прямой ход - приведение к диагональному виду
  int row = 0;
  int col = 0;

  while (row < n && col < m - 1) {
    // Ищем опорный элемент
    int pivotRow = findPivot(row, col);
    
    if (pivotRow == -1) {
      col++;
      continue;
    }

    // Переставляем строку с опорным элементом
    if (pivotRow != row) {
      swapRows(row, pivotRow);
    }

    // Нормализуем текущую строку
    double pivotValue = matrix[row][col];
    if (!isZero(pivotValue)) {
      divideRow(row, pivotValue);
    }

    // Обнуляем текущий столбец во всех других строках
    for (int i = 0; i < n; i++) {
      if (i != row && !isZero(matrix[i][col])) {
        double coeff = matrix[i][col];
        subtractRows(i, row, coeff);
      }
    }

    row++;
    col++;
  }

  // Извлечение решения
  // ... (проверка на противоречивость, rank, извлечение)
}
```

**Параллельная версия (MPI) — синхронизация:**

bool GaivoronskiyMGaussJordanMPI::RunImpl() {
  // ... инициализация и получение матрицы ...

  while (row < n && col < m - 1) {
    int pivot_row = findPivot(col, row);

    if (pivot_row == -1) {
      col++;
      continue;
    }

    if (pivot_row != row) {
      swapRows(row, pivot_row);
    }

    normalizeRow(row, col);

    // Синхронизируем опорную строку перед использованием
    MPI_Bcast(matrix[row].data(), m, MPI_DOUBLE, 0, MPI_COMM_WORLD);

    eliminateColumn(row, col);

    // Синхронизируем всю матрицу после изменений
    for (int i = 0; i < n; i++) {
      MPI_Bcast(matrix[i].data(), m, MPI_DOUBLE, 0, MPI_COMM_WORLD);
    }

    row++;
    col++;
    MPI_Barrier(MPI_COMM_WORLD);
  }

  // Извлечение решения и синхронизация результата
  // ...
}

**Распределение данных в PreProcessing:**

```cpp
bool GaivoronskiyMGaussJordanMPI::PreProcessingImpl() {
  int rank = 0;
  int size = 0;
  MPI_Comm_rank(MPI_COMM_WORLD, &rank);
  MPI_Comm_size(MPI_COMM_WORLD, &size);

  int n = 0;
  int m = 0;

  if (rank == 0) {
    n = static_cast<int>(GetInput().size());
    m = (n > 0) ? static_cast<int>(GetInput()[0].size()) : 0;
  }

  MPI_Bcast(&n, 1, MPI_INT, 0, MPI_COMM_WORLD);
  MPI_Bcast(&m, 1, MPI_INT, 0, MPI_COMM_WORLD);

  if (rank == 0) {
    std::vector<double> flat_matrix(static_cast<size_t>(n * m));
    for (int i = 0; i < n; i++) {
      for (int j = 0; j < m; j++) {
        flat_matrix[static_cast<size_t>(i * m + j)] = GetInput()[i][j];
      }
    }
    MPI_Bcast(flat_matrix.data(), n * m, MPI_DOUBLE, 0, MPI_COMM_WORLD);
  } else {
    std::vector<double> flat_matrix(static_cast<size_t>(n * m));
    MPI_Bcast(flat_matrix.data(), n * m, MPI_DOUBLE, 0, MPI_COMM_WORLD);
    GetInput() = InType(static_cast<size_t>(n), std::vector<double>(static_cast<size_t>(m)));
    for (int i = 0; i < n; i++) {
      for (int j = 0; j < m; j++) {
        GetInput()[i][j] = flat_matrix[static_cast<size_t>(i * m + j)];
      }
    }
  }

  return true;
}
```
